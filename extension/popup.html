Colab Extras

Version 0.8.0

Designed to feel at home in Colab

File and folder tools seamlessly integrated into Google Colab's design and workflow, with familiar menus, theme-aware dialogs, and circular progress indicators.

Right-click a folder in Colab's Files sidebar:

Folder details — total file size, file and subfolder counts, and the 10 largest files.

ZIP only — saves a ZIP next to the folder.

ZIP and download — saves the ZIP and immediately starts downloading it.

Delete folder and contents — permanently removes a folder, including nested files, after confirmation.

Extract here — right-click a ZIP, TAR, TAR.GZ, or TGZ file to unpack it beside the archive. Existing files are never overwritten; the archive is kept.

ZIP actions start with one click. A loading circle appears beside the folder while an operation runs, showing percentage progress when available. Right-click again to cancel a running ZIP or extraction. Refresh Colab after updating the extension.
