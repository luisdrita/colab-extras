Colab Extras

Everyday tools for Google Colab

Right-click a folder in Colab's Files sidebar:

Folder details — total file size, file and subfolder counts, and the 10 largest files.

ZIP only — saves a ZIP next to the folder.

ZIP and download — saves the ZIP and immediately starts downloading it.

Delete folder and contents — permanently removes a folder, including nested files, after confirmation.

ZIP actions start with one click. Progress appears beside the folder. Right-click it again to cancel a running ZIP. Refresh Colab after updating the extension.
