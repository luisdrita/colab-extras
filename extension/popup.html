Colab Extras

Version 0.10.14

Right-click a file or folder in Colab’s Files sidebar to inspect folders, create ZIPs, extract archives, or delete files and folders. Command-click (Mac) or Ctrl-click (Windows/Linux) to select multiple files and folders. Right-click a selected row and use Delete selected items. Deletion starts immediately; affected rows show loading circles.

ZIP and download is always active. Click it to create the ZIP and start downloading automatically.

By default, Extract here creates numbered copies when files or folders already exist.
